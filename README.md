## 📌 Overview

This repository contains the complete, reproducible codebase for the paper:

> **"Beyond Aggregate Indicators: A Multiscale Diagnostic Framework for Urban Green Infrastructure Connectivity Assessment"**

The framework integrates remote sensing (Google Earth Engine), landscape metrics (FRAGSTATS), graph theory (NetworkX), and structural connectivity diagnostics (Conefor) to assess ecological connectivity and planning priorities in fragmented metropolitan landscapes. Tehran, Iran, serves as the empirical demonstrator.

**Key Contributions:**
- Multiscale landscape representation (metropolitan vs. neighborhood)
- Generalized planning-oriented resistance surface
- Graph‑based connectivity diagnosis (IIC, dIIC, dIICflux, dIICconnector)
- Worst‑case node‑removal experiments (structural sensitivity diagnostics)
- Planning‑oriented interpretation classes (Conservation / Reinforcement / Restoration)

🔧 Setup & Installation
1. Clone the repository
bash
git clone https://github.com/yourusername/tehran-ugi-connectivity-framework.git
cd tehran-ugi-connectivity-framework
2. Install Python dependencies
bash
pip install -r requirements.txt
3. Google Earth Engine setup
Create a GEE account at earthengine.google.com

Run 01_preprocess_gee.js in the GEE Code Editor

Export GI_Z.tif and IMP.tif to your Google Drive

Download these files and place them in the data/ folder

4. Generate resistance surface in GEE
Run 02_resistance_layer.js in the GEE Code Editor

Export Resistance.tif to your Google Drive

Place the file in the data/ folder

5. Compute Pearson correlation (optional)
Run 03_gee_correlation.js in the GEE Code Editor

The correlation coefficient will be printed in the console

6. FRAGSTATS (optional)
Landscape metrics (Table 3, Table 4, Table S2–S5) were pre‑computed using FRAGSTATS 4.2. If you wish to recompute them, use the binary UGI layer (GI_binary_85.tif) as input. Results are provided in the manuscript and supplementary material.

7. Conefor 2.6
Download Conefor 2.6 from www.conefor.org

Use the files generated by 04_dijkstra_network.py as input

Run Conefor with the following settings:

Connection type: Distances

Distance threshold: 200 (city), 210 (north), 115 (south)

Metrics: IIC, dIIC

📊 Workflow Execution Order
Step	Script	Description	Input	Output
1	01_preprocess_gee.js	Compute GI_Z and IMP	Landsat 8/9, ESA WorldCover 2021	GI_Z.tif, IMP.tif
2	02_resistance_layer.js	Generate resistance surface	GI_Z.tif, IMP.tif	Resistance.tif
3	03_gee_correlation.js	Compute Pearson correlation	GI_Z.tif, IMP.tif	Correlation coefficient
4	04_dijkstra_network.py	LCPs, cost matrix, IIC, dIIC, Conefor export	Resistance.tif, start_point.shp	Shapefiles, CSVs, Conefor files
🧪 Running the Code (Step‑by‑Step)
Step 1: Google Earth Engine preprocessing
Open GEE Code Editor

Copy the content of src/01_preprocess_gee.js

Run the script and export GI_Z.tif and IMP.tif to Google Drive

Download and place both files in data/

Step 2: Generate resistance surface
Open GEE Code Editor

Copy the content of src/02_resistance_layer.js

Run the script and export Resistance.tif to Google Drive

Download and place the file in data/

Step 3: Compute Pearson correlation (optional)
Open GEE Code Editor

Copy the content of src/03_gee_correlation.js

Run the script and check the console output

Step 4: Run Python network analysis
bash
python src/04_dijkstra_network.py
Before running, configure the paths in the script:

python
RES_PATH = "/content/Resistance.tif"
POINTS_PATH = "/content/start_point.shp"   # City: start_point.shp, North: core_N.shp, South: core_S.shp
REGION_NAME = "City"                       # City / North / South
This script produces:

Output	Description
results/LCP_all_pairs_{REGION}.shp	All least-cost paths between all node pairs
results/Network_P75_{REGION}.shp	Filtered network (75th percentile cost-ratio threshold)
results/Nodes_{REGION}.shp	Ecological core nodes with IDs and areas
results/sensitivity_{REGION}.csv	IIC sensitivity analysis results
results/graph_metrics_{REGION}.csv	Graph theory metrics (degree, betweenness, etc.)
results/dIIC_{REGION}.csv	dIIC values for each node
conefor/nodes_{REGION}.txt	Conefor node file
conefor/connections_{REGION}.txt	Conefor connection file
Step 5: Run Conefor 2.6
Open Conefor 2.6

Load conefor/nodes_{REGION}.txt and conefor/connections_{REGION}.txt

Set distance threshold (city: 200, north: 210, south: 115)

Select IIC and dIIC

Run and save output
