# Results Directory

This folder contains output files generated by `src/04_dijkstra_network.py`.

## Shapefiles (for mapping)

| File | Description |
| :--- | :--- |
| `LCP_all_pairs_{REGION}.shp` | All least-cost paths between all node pairs |
| `Network_P75_{REGION}.shp` | Filtered network (75th percentile cost-ratio threshold) |
| `Nodes_{REGION}.shp` | Ecological core nodes with IDs and areas |

## CSV Files (tabular data)

| File | Description |
| :--- | :--- |
| `sensitivity_{REGION}.csv` | IIC values for P50, P60, P75, P90 thresholds |
| `graph_metrics_{REGION}.csv` | Graph theory metrics (degree, betweenness, closeness, eigenvector) |
| `dIIC_{REGION}.csv` | dIIC values for each node (node removal analysis) |

## Images

| File | Description |
| :--- | :--- |
| `sensitivity_plot_{REGION}.png` | IIC sensitivity analysis plot |

## Binary files (for reproducibility)

| File | Description |
| :--- | :--- |
| `cost_matrix_{REGION}.npy` | Pairwise cost matrix (NumPy format) |
| `graph_{REGION}.pkl` | NetworkX graph object (pickle format) |
| `areas_{REGION}.npy` | Node areas array (NumPy format) |

## Regions

| REGION | Description | Number of nodes |
| :--- | :--- | :--- |
| `City` | Full metropolitan network | 34 |
| `North` | Northern subnetwork | 26 |
| `South` | Southern subnetwork | 8 |
| `South_30` | Southern subnetwork after removing Node 30 | 7 |

## Notes

- These files are generated automatically by the code
- Shapefiles can be opened in GIS software (QGIS, ArcGIS) for mapping
- CSV files can be opened in Excel or any text editor
- The sensitivity plots are used in the manuscript (Figure 5)
