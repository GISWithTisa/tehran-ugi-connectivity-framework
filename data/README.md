# Data Directory

This folder contains input data required to run `src/04_dijkstra_network.py`.

## Files

| File | Description | Source |
| :--- | :--- | :--- |
| `Resistance.tif` | Ecological resistance surface | Generated by `src/02_resistance_layer.js` in GEE |
| `GI_Z.tif` | Green infrastructure quality index | Generated by `src/01_preprocess_gee.js` in GEE |
| `IMP.tif` | Impervious surface density | Generated by `src/01_preprocess_gee.js` in GEE |
| `start_point.shp` | Full city ecological cores (34 nodes) | Extracted from ArcGIS |
| `core_N.shp` | Northern subnetwork cores (26 nodes) | Subset of `start_point` |
| `core_S.shp` | Southern subnetwork cores (8 nodes) | Subset of `start_point` |
| `core_S_30.shp` | Southern cores after removing Node 30 (7 nodes) | Manually edited from `core_S.shp` |
| `mahale_352.shp` | Tehran neighborhood boundaries | Tehran Municipality / GEE Asset |

## Coordinate System

- EPSG:32639 (UTM Zone 39N)
- Resolution: 30 m for raster files

## Notes

- All shapefiles must include `.shp`, `.shx`, `.dbf`, `.prj` files
- The `Area_ha` field is required for nodes shapefiles
